#### 🚀 Getting Started
Prerequisites
Python 3
Git
A code editor such as Visual Studio Code
Clone the Repository
git clone https://github.com/im-anoop/aibootcamp.git

Navigate to the Project
cd aibootcamp

Create a Virtual Environment
python -m venv .venv

Activate the Virtual Environment

Windows PowerShell:

.\.venv\Scripts\Activate.ps1

Run the Python Application
python main.py


Install additional dependencies as required by each project. If a requirements.txt file is provided, install the dependencies with:

pip install -r requirements.txt
